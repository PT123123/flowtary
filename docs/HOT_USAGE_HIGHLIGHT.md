# 使用分档醒目样式（Usage Tiers Highlight）

搜索结果里「平时有使用」的条目按使用历史分档施加醒目样式；没用过 / 偶尔用的条目保持原样——
哪怕它同在开始菜单这类规定目录下。判定与当前输入的词无关，衡量的是目标本身的使用历史。

## 判定

- 使用次数 = 该完整路径在**全部搜索词**下的点击权重之和（`weights.dat`）
  + 自学习打开次数之和（`learned.dat`）。跨词求和，路径统一小写后匹配。
- 回填时机：`Layout()` 入口的 `AnnotateRowUsage()`，每次布局全量重算
  （条目上限 5000 + 500，一次哈希遍历 <1ms），结果存 `Row::usage`。
- 适用行：`Prog` / `File` / `Folder`。网页、一键组、窗口切换等不参与。

## 分档 + 连续热度

`UsageTier()`（src/main.cpp）：

| 档 | 次数 | 档名 | 视觉 |
| --- | --- | --- | --- |
| 0 | 0–2 | — | 完全原样：无条、无染、无徽章、常规字 |
| 2 | 3–9 | 常用 | 加粗 + 强调色标题；3px 胶囊色条；淡底胶囊徽章「常用 ×N」+ 档点 |
| 3 | 10–29 | 高频 | 4px 胶囊色条；浓底 + 描边胶囊徽章「高频 ×N」+ 档点 |
| 4 | ≥30 | 重度 | 5px 胶囊色条 + 外罩软辉光；实底反白胶囊徽章「重度 ×N」；标题后低 alpha 圆角辉光 |

档内再连续渐变，避免一刀切：`UsageHeat()` = ln(1+次数)/ln(65) 截到 0..1
（1→0.17，3→0.33，15→0.66，25→0.78，29→0.82，64+→1），驱动

- 行底染色 alpha = 0.04 + 0.14×heat（同档 15 次与 25 次底色不同）；
- 选中行热叠色 alpha = 0.06 + 0.10×heat（选中态也保留热度层次）；
- 标题混色见下「主题感知墨色」。

## 设计语言

- **胶囊色条**：行最左缘外侧边距 x=S(2)（图标从 `pad` 起绘，会盖住卡片左缘的同位置色条）。
  宽度随档 3/4/5px，圆角=半宽成胶囊；`FillRoundRectVGradient` 做 accent2→accent 垂直渐变。
  重度档在色条外再罩一圈 `PaintOutShadow` 软辉光（alpha 46），把最高档托出来。
- **徽章胶囊**：radius=半高；左端 5px 档点 + 左对齐「档名 ×N」。档 2 淡底、档 3 浓底加描边、
  档 4 强调色实底反白字。徽章让位计入副标题/标题宽度预算（`hotReserved`），深路径省略号逻辑不变。
- **标题辉光**：重度档在字后罩一层 alpha 26 的圆角辉光（宽度=字宽+4），像荧光笔托底但不抢字。
- **染色边界**：行底染色 / 选中热叠色只落在卡片横向范围 `cardRow` 内；边距留给窗体底与卡片外影，
  整行铺满会把浅色主题右侧/底部的软影切出缺口。
- **主题感知墨色**：深色主题标题 = Blend(基色, textBody, 0.42 − 0.34×heat)（越热越纯越亮）；
  浅色主题反向 = Blend(基色, textBody, 0.30 + 0.40×heat)，且重度基色改用 Darken(accent,25)，
  让「越常用」在浅底上呈现为**更深、对比更强**的墨色，而不是更淡的强调色（浅底淡蓝字对比不足）。

## 两个 GDI 坑（已修，勿回退）

- **预乘 alpha**：`PaintOutShadow` 走 `AlphaBlend(AC_SRC_ALPHA)`，源 RGB 必须预乘 alpha。
  不预乘时 `src + dst*(1-a)` 在亮色上溢出**回绕**（B 通道 273→17），辉光会变成杂色酸绿块。
  黑色阴影因 src=0 永不溢出，所以旧代码只画黑影时看不出问题。现源色按 `col*a/255` 预乘。
- **RoundRect path 少一像素**：GDI 圆角/矩形 path 不含右/下边缘，做 clip 时会比请求窄 1px。
  `FillRoundRectVGradient` 用 `right+1 / bottom+1` 补回，保证色条宽度=请求宽度。

## 验证

`tests/hot_usage_ui_test.cpp`（ctest 名 `hot_usage_ui`）包含生产 main.cpp，
种入跨词权重 + 自学习数据（15/1/3/0/25/40 六行），驱动真实 `Layout()+Paint()` 画进 DIB：

- 数据臂：跨词求和 5+7+3=15；档边界 0/2、3/9、10/29、30+；heat 单调；
- 字体臂：加粗字体存在、tmWeight≥FW_BOLD、同串更宽；
- 像素臂（暗/浅两主题）：各档色条宽度内外采样、重度色条辉光 = Blend(bg,accent2,46/255)、
  高频无辉光、徽章三形态 + 档点 + 反白字芯、同档不同次数染色不同且单调 3<15<25<40、
  染色不出卡片边距、选中行热叠色、重度标题辉光 = Blend(染色,accent2,26/255)、
  浅色主题各档墨色存在且重度对比强于常用档、原样行零标记；
- 对照臂：清空权重与自学习后重画，全部醒目样式必须消失（证明门认数据不认常量）。

BMP 落盘（运行目录）供肉眼复核；32 位 DIB alpha 未定义，取证图强制 255 再转 PNG
（build/hot_usage_{dark,light,control}.png）。

Mutant 自证：`bash tools/mutant_hot_usage.sh`。在 build/mutant 副本里先跑逐字节相同的
控制副本（必须全绿），再把 `UsageTier` 的高频档条件行 `return 3` 改成 `return 2`
（只改条件行），门必须红在 `FAIL: tier 3 spans 10-29`；两腿任一不符即脚本退出 1。
