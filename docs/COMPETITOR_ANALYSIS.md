## Flowtary 核心优势（差异化护城河）

- **极致轻量**：~186KB exe，~4MB 内存，零依赖，纯 Win32+GDI
- **启动极快**：托盘优先创建，程序扫描异步线程
- **零资源图标**：系统字体现场绘制，无 .ico 依赖
- **中文 IME 完美支持**：组合串/候选窗锚定光标
- **点击加权排序**：按搜索词独立记忆，持久化存储
- **一键启动/关闭组**：批量操作，无控制台窗口
- **文件对话框跳转**：类 Listary Quick-Switch
- **丰富主题系统**：8 预设 + 材质(Mica/Acrylic) + 微调滑块

## 关键架构决策（已确认）

### 1. **坚持「单文件/零依赖/极简」核心定位**
- 不引入插件系统、WebView2、Python/Node 运行时
- 所有功能内置 C++ 实现
- 保持 ~200KB exe、~5MB 内存、零外部依赖

### 2. **Phase 1 优先实现：Shell 命令 (>) + 窗口切换 (<)**
- 用户明确指定的最高优先级
- 实现后直接解决开发者"跑命令"和"切窗口"两大高频痛点

### 3. **预览面板技术路线：IPreviewHandler (系统原生)**
- 零依赖，支持 Office/PDF/图片/文本，Win7+ 原生
- 无 Handler 时回退：图片用 GDI+，文本/代码用 RichEdit/自绘

## 实施路线图

Phase 1 (当前) - Shell 命令 + 窗口切换
├── `>` Shell 命令执行 (支持 Ctrl+Shift+Enter 提权)
├── `<` 窗口切换 (枚举/分组/模糊匹配/切换/关闭/杀进程)
└── 设置页新增 Tab"Shell 与窗口"完整配置

Phase 2 (后续) - 计算器/单位换算/进制转换 (`=` 前缀)
├── 微型表达式解析器 (递归下降)
├── 内置单位换算表
└── 进制自动识别 (0x/0b/0o)

Phase 3 (后续) - 系统命令 + 值生成器 + 高级搜索语法
├── shutdown/restart/sleep/lock/emptybin 等系统命令
├── # uuid / # md5 / # base64 / # pass 等值生成器
└── ext:/date:/size:/"精确"/-排除 语法解析

Phase 4 (后续) - IPreviewHandler 预览面板
├── 宿主窗口 + 分割线拖拽调整
├── COM 调用 IPreviewHandler
└── 无 Handler 时多格式回退渲染

Phase 5 (后续) - 浏览器书签 + 剪贴板历史 + 交互打磨
├── Chrome/Edge/Firefox/Vivaldi 书签解析
├── WM_CLIPBOARDUPDATE 监听 + 环形缓冲区
